# Material intake workspace

User-confirmed direction: a code-Agent-like desktop workspace centered on real document results, with a stable workflow rail and concise contextual assistance.

- Cool near-white workspace, dark slate navigation, indigo primary actions.
- Local system UI fonts, Chinese-first task copy; no online font dependency.
- Material rows group filename, file size, editable role and per-file instruction.
- Exactly one primary PPTX. Reference files never silently become main content.
- Separate save and save-with-statistics actions. Display actual tool output rather than fabricated AI recommendations.
- Recent projects allow reopening and updating the same record.
- Desktop target: 1440×960 and 1000×760. Narrow desktop layout collapses the helper column.
- Visible focus rings, real input labels, reduced-motion support, explicit missing-tool and analysis-failure states.

Agent chat, preview canvas, skill management and full-deck production remain future surfaces.
